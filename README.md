# 笔墨通心

中国画美育疗法数据可视化纯前端项目。页面使用 JavaScript 和 ECharts 实现，主要面向 `1920 × 1080` 大屏展示。当前页面数据已经接入 `realdata/` 中的工作簿。

## 运行方式

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 页面

| 地址 | 页面 |
| --- | --- |
| `/?page=status` | 大学生心理问题现状总览 |
| `/?page=therapy` | 传统心理疗法优缺点分析 |
| `/?page=trend` | 中国画美育疗法趋势 |
| `/?page=technique` | 中国画技法针对性 |
| `/?page=comparison` | 中国画疗法与传统疗法综合对比 |

页面支持顶部导航切换。鼠标滚轮到达当前页底部后继续向下滚动，也会自动进入下一页；最后一页不会继续跳转。

## 目录结构

```text
src/
├── app.js                 # 应用装配
├── main.js                # 启动入口
├── state.js               # 页面状态
├── charts/                # ECharts 图表模块
├── components/            # 顶栏、弹窗等通用组件
├── data/                  # 前端结构化数据
├── interactions/          # 事件、弹窗内容、国画热区
├── pages/                 # 五个页面模板
└── styles/                # 基础、布局、组件和页面样式
```

国画图片位于 `public/images/chinese-painting.jpg`。

## 数据来源

| 文件 | 用途 |
| --- | --- |
| `realdata/心理问题人数及患病率.xlsx` | 心理现状页 |
| `realdata/经典四种心理疗法细分交叉统计表.xlsx` | 传统疗法页 |
| `realdata/2015-2025全国大学生中国画美育疗法数据趋势表.xlsx` | 国画趋势页 |
| `realdata/五大疗法与四类心理问题独立细分矩阵表.xlsx` | 综合对比页 |

页面五雷达图中的起效周期、安全性和成本根据原表定性等级进行了正向归一化，越靠近雷达图边缘代表综合表现越优。

注意：国画趋势工作簿注明，该表全国层面的垂直统计基于高校实践案例、部分公开研究样本和文献发展趋势进行综合推演与均值建模，并非单一官方发布口径。
